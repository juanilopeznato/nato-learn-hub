# NATO University (nato-learn-hub)

| Campo | Valor |
|---|---|
| Tipo | software (plataforma LMS multi-escuela) |
| Objetivo | Vender cursos online con plataforma propia de NATO: cada escuela tiene sus alumnos, su marca y su cuenta de Mercado Pago; NATO cobra comisión y planes |
| Estado | brownfield (desde 2026-04; lanzamiento del curso «Edición Limitada» en jun-2026) |
| Alcance | en producción |
| Cliente / dueño | NATO (Juani). Primera escuela: Nata Álvarez |
| Repo remoto | github.com/juanilopeznato/nato-learn-hub (**público**) |
| Producción | https://university.natoglobal.com.ar según los textos del código desde 2026-06-17; también https://natouniversity.lovable.app. PENDIENTE: confirmar con Juani cuál es la vigente |

## En una frase
LMS tipo Teachable propio: landing, catálogo, página de curso con checkout (también sin cuenta), reproductor de lecciones protegido, comunidad, panel de instructor, panel de NATO y emails.
